Remaining limitations and next updates

  1. Table 21 interpretation: the additive reading has historical closing-value gaps of about 0.8–2.1%. Opening product-level allocation is estimated; the manual's exact weighted timing is not fully established. The legacy pool remains a sensitivity, not the default.
  2. Payroll: weekly parity exposure, attendance, resignations, strikes and recruitment supply remain approximations. Full versus half-quarter parity is explicitly tested.
  3. Official hidden functions: demand elasticity, advertising/quality response, R&D success, share-price sentiment and rival reactions are model assumptions. Improvement launch is wired, but the official strength/timing of demand gains is unknown; R&D process state needs more history calibration.
  4. Operations: website peak congestion, return freight, agent-dependent journey length, random breakdowns and insurance claims remain simplified. Factory people/machine limits are enforced, but simultaneous project prioritization is a stated model choice.
  5. Carbon: Q1 Table 27 reconstruction remains 1.56555 t below the reported figure. No balancing amount was inserted.
  6. Finance: daily overdraft exposure is not modeled. Future overdraft-limit rounding remains an assumption. Terminal payout strategies can exploit the proxy; use cash, NAV return and uncertainty tables alongside it.
